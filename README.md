# WAGAYA. | 山本雅茂 公式サイト

## 概要

山本雅茂（Shige）の公式サイトです。教育や国際協力の活動、ケニアでのJICA海外協力隊の経験、講演実績を日本語と英語で紹介しています。

- **Knowledge Library**（`/library`）では、野球と英語学習の参考動画や記事をテーマ別に探せます。
- **編集室**（`/studio`）では、Sanity Studioからサイトの日英の文言やYouTubeリンク、Knowledge Libraryの動画情報を編集できます。

## 使用技術

| 技術 | 用途 |
| --- | --- |
| Next.js 16（App Router）、React 19、TypeScript | ページの構成とUIの実装 |
| Tailwind CSS 3、PostCSS | スタイルの実装 |
| Framer Motion | ページ内のアニメーション |
| Lucide React、Radix UI Slot | アイコンの表示とボタンコンポーネントの実装 |
| Sanity、Sanity Studio、next-sanity | コンテンツの管理とNext.jsへの組み込み |
| Node.js 26、npm | 開発環境とパッケージ管理 |
| ESLint、Prettier | 静的解析とコード整形 |
